# Settings

Admin-editable site settings (brand, contact, social, feature flags) read through a cached repository.

Folders (created only when first needed): `Models/`, `Actions/`, `Data/`, `Contracts/`, `Repositories/`, `Events/`, `Enums/`, `Observers/`. Bindings live in `App\Providers\Domain\SettingsServiceProvider`. See `docs/ARCHITECTURE.md`.
