# ریتمی — بسته سایت استاتیک (HTML / CSS / JS) برای وردپرس

نسخه ۱.۰ · مهر ۱۴۰۵ · ۲۹ صفحه · ریسپانسیو (۳۹۰ تا ۱۴۴۰) · فونت‌ها self-host (Vazirmatn + Lalezar؛ وابسته به Google Fonts نیست)

## چه چیزی داخل بسته است

```
ritme-site/
  index.html, cycle.html, ttc.html, pregnancy.html, postpartum.html, menopause.html, teen.html,
  services.html, plus.html, blog.html, article.html, tools.html, about.html, contact.html,
  social-responsibility.html, faq.html, privacy.html,
  directory*.html (۶ صفحه خدمات مادر و کودک) · shop*.html (۶ صفحه فروشگاه)
  assets/ritme.css       ← استایل مشترک + ریسپانسیو + @font-face
  assets/ritme.js        ← منوی موبایل + محاسبه‌گرهای شمسی (تاریخ زایمان، روزهای باروری)
  assets/fonts/*.woff2   ← Vazirmatn 400–800 و Lalezar 400 (عربی + لاتین)
  wordpress/
    snippets/*.html      ← همان صفحه‌ها، فقط محتوای <body>، آماده‌ی چسباندن در ویجت HTML المنتور
    uploads-ritme/       ← ritme.css + ritme.js + fonts برای آپلود در /wp-content/uploads/ritme/
    page-ritme-static.php← قالب صفحه برای چایلد تم (روش ج)
```

هر صفحه یک فایل کامل و مستقل است: فقط `assets/ritme.css` و `assets/ritme.js` را می‌خواهد. هیچ تصویر بیرونی، CDN یا کتابخانه‌ای لازم نیست (همه تصویرسازی‌ها SVG داخلی‌اند).

## سه راه بارگذاری در وردپرس

### روش الف — استاتیک کنار وردپرس (ساده‌ترین، سریع‌ترین)
1. پوشه `ritme-site` را با نام `ritme-static` در ریشه هاست (کنار `wp-admin`) آپلود کنید.
2. آدرس‌ها می‌شود `https://example.com/ritme-static/cycle.html` و می‌توانید در منوی وردپرس به آن‌ها لینک بدهید.
3. برای این‌که صفحه اصلی سایت همین `index.html` باشد، در `.htaccess` بالای قوانین وردپرس اضافه کنید:
   ```
   DirectoryIndex ritme-static/index.html index.php
   ```
   (یا فقط صفحه اصلی را با روش ب/ج بسازید.)

مزیت: صفر وابستگی به تم و پلاگین، سرعت بالا. محدودیت: این صفحه‌ها هدر/فوتر تم وردپرس را ندارند (هدر و فوتر خودشان را دارند).

### روش ب — المنتور (ویجت HTML)
1. پوشه `wordpress/uploads-ritme` را در مسیر `/wp-content/uploads/ritme/` آپلود کنید (باید `ritme.css`، `ritme.js` و پوشه `fonts` آنجا باشند).
2. یک صفحه بسازید → ویرایش با المنتور → از تنظیمات صفحه (چرخ‌دنده پایین چپ) قالب صفحه را روی **Elementor Canvas** بگذارید (بدون هدر/فوتر تم).
3. یک ویجت **HTML** بکشید و محتوای `wordpress/snippets/<نام‌صفحه>.html` را داخل آن بچسبانید. لینک CSS/JS در ابتدای هر اسنیپت هست.
4. لینک‌های داخلی اسنیپت‌ها به شکل `/cycle/`، `/tools/` … نوشته شده‌اند؛ نامک (slug) صفحه‌های وردپرس را همین بگذارید.

نکته: المنتور محتوای ویجت HTML را دست نمی‌زند، ولی اگر «بهینه‌سازی CSS» پلاگین‌های کش فعال است، `ritme.css` را از فشرده‌سازی مستثنا کنید (attribute selectorهای `[style*=…]` باید سالم بمانند).

### روش ج — قالب صفحه در چایلد تم (بهترین برای مدیریت از داشبورد)
1. `wordpress/page-ritme-static.php` را در پوشه چایلد تم بگذارید.
2. پوشه `ritme-site` را با نام `ritme-static` در ریشه وردپرس آپلود کنید.
3. برای هر صفحه وردپرس، قالب **Ritme Static Page** را انتخاب کنید و **نامک صفحه را برابر نام فایل** بگذارید (`cycle`، `tools`، `about`…). صفحه اصلی: `index.html` خودکار.

## چیزهایی که باید وصل کنید
- فرم تماس (`contact.html`) استاتیک است؛ با فرم المنتور یا افزونه فرم جایگزین کنید (متن «اطلاعات سلامت ننویس» را نگه دارید).
- دکمه‌های «ورود» و «دانلود اپ» به `#` و `#download` می‌روند؛ لینک فروشگاه‌ها (کافه‌بازار، مایکت، …) را بگذارید.
- `[اینماد]`، `[ایمیل مسئول داده]` و هر متن داخل کروشه placeholder است.
- `blog.html` و `article.html` فقط پیش‌نمایش استاتیک مجله‌اند؛ بلاگ واقعی با قالب المنتور جداگانه (بسته `ritme-elementor-blog`) ساخته می‌شود.
- محاسبه‌گرهای صفحه ابزارها واقعی‌اند (JS، تقویم شمسی): ورودی تاریخ به شکل `۱۴۰۵/۰۲/۱۲` یا «۱۲ اردیبهشت ۱۴۰۵». هشدار «روش پیشگیری نیست» بالای نتیجه است.

## ریسپانسیو چطور کار می‌کند
طرح‌ها روی گرید ۱۴۴۰ ساخته شده‌اند و استایل‌ها inline هستند. `ritme.css` با attribute selector روی همان استایل‌ها در سه نقطه شکست (۱۱۸۰ / ۱۰۲۴ / ۷۰۰ پیکسل) گرید‌ها را تک/دوستونه، حاشیه‌ها را ۲۰ پیکسل و تیترها را کوچک‌تر می‌کند و منوی همبرگری را روشن می‌کند. اگر بخش جدیدی اضافه می‌کنید، از همان الگوهای `padding:…120px` و `grid-template-columns:repeat(n,…)` استفاده کنید تا خودکار ریسپانسیو شود.
