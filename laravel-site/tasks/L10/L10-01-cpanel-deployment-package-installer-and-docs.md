# L10-01 — cPanel deployment package, installer and docs

## Why
The site may run on shared cPanel hosting: no root, often no Node, no symlinks, no Supervisor, PHP via
LiteSpeed/Apache.

## Scope
- `deploy/build-cpanel.sh`: clean checkout → `composer install --no-dev --optimize-autoloader --classmap-authoritative`
  → `npm ci && npm run build` (+ SW) → zip without `node_modules`, `tests`, `design`, `tasks`, `docs`, `tools`,
  `.git`, dev configs → `dist/ritme-site-<version>.zip` + checksum.
- Two supported layouts documented and tested locally: (A) document root → `public/`; (B) app outside
  `public_html` with `public_html` holding `public/*` and a patched `index.php` path (generated by the script with
  `--layout=public_html`), plus fallback root `.htaccess` that rewrites to `public/` when the doc root can't change.
- `php artisan app:install` (checks PHP version + extensions (gd/imagick, intl, mbstring, pdo_mysql, fileinfo,
  exif), writable dirs, generates key if missing, migrates, seeds production defaults, creates the admin, warms
  caches) and `app:upgrade` (maintenance mode with secret, migrate --force, `optimize`, bump cache namespaces,
  `up`). Web-less: run via cPanel Terminal or a one-off cron.
- Scheduler (`routes/console.php`): queue worker `queue:work --stop-when-empty --max-time=55` every minute,
  scheduled posts, sitemap warm, audit weekly, 404 log purge, backups; one cPanel cron line documented.
- `.env.cpanel.example` (MySQL, `CACHE_STORE=file` or `database`, `SESSION_DRIVER=file`, `QUEUE_CONNECTION=database`,
  `MEDIA_DISK_ROOT`, mail SMTP of the host).
- `docs/DEPLOY-CPANEL.md` **in Persian**, step by step with screenshots placeholders: create DB, upload zip, extract,
  set PHP version (MultiPHP), env, install command, cron, SSL (AutoSSL), troubleshooting (500 errors, permissions,
  `open_basedir`, missing extensions).

- From L9-01/L8-02: build the package with `CRITICAL_STRICT=1 npm run build` (critical CSS per template + SW);
  ship `public/build/critical/`, `public/sw.js`, `public/build/build-id.json`; post-deploy run
  `php artisan cache:ns bump pages` (cached HTML carries the critical-CSS hash allowed by the CSP).

## Acceptance
- Package installs on a clean local Apache/PHP container simulating cPanel (both layouts) and serves the site; docs
  reviewed.
